Starred OCR projects checked but not usable here

SwiftOCR

  • Repo: NMAC427/SwiftOCR
  • License: Apache-2.0
  • Why not: Swift for iOS and macOS apps, can't run in a web page.

GLM-OCR

  • Repo: zai-org/GLM-OCR
  • License: Apache-2.0
  • Why not: A large Python model that needs a server or GPU.

DeepSeek-OCR

  • Repo: deepseek-ai/DeepSeek-OCR
  • License: MIT
  • Why not: A large Python model that needs a GPU.

DeepSeek-OCR-2

  • Repo: deepseek-ai/DeepSeek-OCR-2
  • License: Apache-2.0
  • Why not: Same: Python and a GPU.

ocr_digital_screen_reader

  • Repo: emirbaycan/ocr_digital_screen_reader
  • License: GPL-3.0
  • Why not: Python, and only reads digits on device screens.

CK3-OCR

  • Repo: Agamidae/CK3-OCR
  • License: No license
  • Why not: AutoHotkey for Windows, and no license.

The gap

No browser OCR library (like Tesseract.js) is in the starred list, so GameSpeak uses the browser's built-in TextDetector where it exists. Most browsers, including iPhone Safari, don't have it yet.
